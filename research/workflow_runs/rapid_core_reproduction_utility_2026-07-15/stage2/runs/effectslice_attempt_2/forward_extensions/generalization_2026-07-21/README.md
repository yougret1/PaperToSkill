# EffectSlice Forward Generalization Extension

This directory records forward-only work performed after the accepted V4/V5
proof-of-concept evidence and the passed Stage 2 report. It does not supersede,
rewrite, or reopen any V4/V5 preregistration, raw output, analysis, or release
binding.

The extension follows the existing numbered Stage 2 contracts. Each attempted
sub-stage receives a local `stage_report_*.json` in this directory and cites the
accepted parent run as immutable input.

Current scope:

- Stage `2.6`: broaden and formally verify the related-work evidence.
- Stage `2.2`: preregister the multi-paper forward experiment.
- Stage `2.3`: run adapter pilots and the frozen generalization batches.
- Stages `2.4` through `2.8`: consolidate evidence, figures, manuscript, and
  independent review.

The user requires a private Git backup after each completed forward stage.
