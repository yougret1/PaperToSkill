```python
def solve(case):
    nodes = case["nodes"]
    required_symbols = set(case["required_symbols"])

    # Build child-list index
    node_map = {n["id"]: n for n in nodes}
    children = {n["id"]: [] for n in nodes}
    for n in nodes:
        if n["parent"] is not None:
            children[n["parent"]].append(n["id"])

    # All nodes start retained
    retained = {n["id"] for n in nodes}

    # Process deeper nodes first; use node ID as stable tie-break at equal depth
    candidates = sorted(nodes, key=lambda n: (-n["depth"], n["id"]))

    removal_order = []

    for node in candidates:
        nid = node["id"]

        # Hard guards: not removable, is root, or symbol is required
        if not node["removable"]:
            continue
        if node["parent"] is None:
            continue
        if node["symbol"] in required_symbols:
            continue

        # Cannot remove a node that still has retained children
        if any(c in retained for c in children[nid]):
            continue

        # Tentative removal: verify all required symbols remain covered
        retained.remove(nid)
        covered = {node_map[r]["symbol"] for r in retained}

        if required_symbols.issubset(covered):
            removal_order.append(nid)          # confirmed removal
        else:
            retained.add(nid)                  # restore — symbol coverage would break

    return {
        "retained_ids": sorted(retained),
        "removal_order": removal_order,
    }
```

**How it works:**

- Candidates are visited deepest-first so leaf nodes are evaluated before their ancestors, which lets parents become removable once their children are gone.
- The four hard guards (non-removable, root, required symbol, has retained children) are checked before any mutation.
- The tentative-removal check is the only place where we temporarily modify `retained`; if coverage of `required_symbols` breaks, the node is restored immediately.
- `retained_ids` is returned lexicographically sorted; `removal_order` records the sequence in which nodes were actually dropped.
