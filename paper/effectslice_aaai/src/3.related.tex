\section{Related Work}

\subsection{From Papers to Executable Agent Artifacts}

Recent systems turn scientific or external knowledge into executable research objects. PaperBench, AutoReproduce, RExBench, and REPRO-Bench evaluate code reconstruction, experiment reproduction with paper lineage, implementation of research extensions, and reproducibility assessment \cite{starace2025paperbench,zhao2025autoreproduce,edwards2026rexbench,hu2025reprobench}. Complementary construction systems organize source material as executable knowledge graphs, interactive paper agents, reusable toolsets, or skill libraries \cite{luo2026xkg,miao2025paper2agent,ma2025reusabletoolsets,shen2026skillfoundry,pan2026anything2skill}. These systems ask how to construct or reproduce a useful artifact. SkillAudit begins after construction: it takes a fixed full artifact and a fixed simplified candidate as inputs, then evaluates a bounded substitution claim.

\subsection{Context and Skill Compression}

Prompt compression reduces model-facing context while attempting to preserve downstream behavior. LLMLingua and LongLLMLingua use token-level and question-aware compression; LLMLingua-2 reframes selection as token classification; later methods use sentence encoders, error-aware optimization, or training-free perception \cite{jiang2023llmlingua,jiang2024longllmlingua,pan2024llmlingua2,liskavets2025contextcompression,larionov2025promptoptme,tang2025perception}. Agent-oriented work extends this objective to reusable instructions and skills \cite{gao2026skillreducer,xu2026compression}. In particular, SkillReducer compares no-skill, original, and compressed conditions, validates candidates in a real environment, and restores removed units after failures \cite{gao2026skillreducer}. SkillAudit does not claim these operations as new. Its narrower focus is a registry-mappable paper-derived candidate whose decision is bound to source locations, declared dependencies, a fixed task boundary, explicit invalid or inconclusive states, and a replayable evidence record.

\subsection{Agent and Evaluator Validation}

Tool-learning systems study tool construction, invocation, general-ability preservation, and efficient selection \cite{schick2023toolformer,gao2024confucius,hao2025citi,ma2025reusabletoolsets,jia2026autotool}. AgentBoard, MCP-AgentBench, and Beyond Accuracy instead emphasize intermediate progress, protocol-aware interaction, evaluator validity, task difficulty, capability boundaries, and execution cost \cite{ma2024agentboard,guo2026mcpagentbench,wang2026beyondaccuracy}. Paper-reproduction benchmarks similarly freeze tasks or rubrics to distinguish system capability from evaluation artifacts \cite{starace2025paperbench,zhao2025autoreproduce}. These benchmarks produce scores, rankings, or capability profiles for complete agents. SkillAudit changes both the evaluation object and the output: it diagnoses whether $B$ is nondiagnostic, whether $F$ is sufficient, and whether $S$ has matched evidence for local substitution, while retaining an explicit invalid state and source-linked record.
