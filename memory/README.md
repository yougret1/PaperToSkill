# Project Memory

This directory contains concise project memory. Workflow stage reports under
`research/workflow_runs/` are the authoritative progress records.

## Current Files

- `summary.md`: stable project goal, scope, decisions, and current run.
- `shortMemory.md`: active working context for the current iteration.
- `next.md`: next actions, risks, questions, and blockers.
- `logs/`: chronological memory iteration records.

## Legacy Compatibility Files

- `long_term_memory.md`
- `short_term_memory.md`

The two legacy files are preserved because existing reproducibility scripts and
reports reference them directly. They are historical inputs, not the canonical
current memory. Their migration is tracked in
`research/workflow_runs/legacy_papertoskill_v1/migration_map.md`.
